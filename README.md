# Лексика

Персональный офлайн-тренажёр английских слов. Словари, настройки и история оценок хранятся в IndexedDB текущего браузера; серверной части и передачи данных нет.

## Запуск

Требуется Node.js 20 или новее.

```sh
npm ci
npm run dev
```

Vite покажет локальный адрес. Для production-сборки и локального предпросмотра:

```sh
npm test
npm run build
npm run preview
```

## Excel

Импортируется первый лист файла `.xlsx`. Первая строка должна содержать семь заголовков: `English`, `Russian`, `Transcription`, `Past Simple`, `Past Participle`, `Example EN`, `Example RU`. Обязательны только первые два поля. Формулы не вычисляются, ячейки с формулами не импортируются как текст.

Импорт поддерживает книги с XML-префиксами и абсолютными ссылками на таблицы, которые встречаются при сохранении в разных редакторах Excel. При необходимости служебная структура преобразуется в памяти; исходный файл сохраняется без изменений. Ошибки чтения сопровождаются подсказкой: проверить формат `.xlsx`, скачать файл на устройство или сохранить новую копию книги без пароля.

Сгенерировать заполненный пример-шаблон можно командой `npm run template`; файл появится как `Шаблон словаря.xlsx` в корне проекта. Импорт и чтение Excel выполняются локально в браузере.

Повторный импорт заменяет состав выбранного словаря после подтверждения. Пары EN/RU сравниваются без учёта регистра и лишних пробелов. Общая пара в разных списках использует одну карточку и общую историю повторов.

## Данные и резервная копия

Настройки, импорт/обновление списков, статистика и ручные JSON-копии находятся за кнопкой настроек. Резервная копия включает версии формата и базы, словари, карточки, связи, историю оценок, настройки и техническую историю недавнего выбора. Восстановление сначала проверяет структуру и ссылки и заменяет базу одной транзакцией.

Данные не синхронизируются между устройствами. Очистка данных браузера, удаление установленного PWA или смена телефона могут привести к потере словарей и статистики. Сохраняйте копии в отдельном надёжном месте.

## GitHub Pages

Включите GitHub Actions как источник GitHub Pages. Workflow `.github/workflows/deploy.yml` собирает приложение с базовым путём `/<имя-репозитория>/` и публикует `dist`. Для ручной сборки с этим путём:

```sh
VITE_BASE_PATH=/english-trainer/ npm run build
```

При сборке автоматически создаётся `dist/sw.js` со списком всех файлов приложения, включая модуль чтения Excel, стили, иконку и manifest. Первая загрузка сохраняет весь комплект для работы без сети. Версия кеша зависит от содержимого сборки; кеш изолирован по пути приложения на GitHub Pages.

Обновление устанавливается только после успешной загрузки всех файлов и применяется после закрытия всех вкладок приложения и установленного PWA. До этого работает предыдущая версия. Обновление кеша не затрагивает IndexedDB и прогресс.

## Проверка работы без интернета

1. Выполните `npm run build` и `npm run preview`, откройте адрес на `localhost`. Либо используйте опубликованное приложение по HTTPS. В `npm run dev` офлайн-кеширование отключено.
2. Дождитесь надписи **«Готово к работе без интернета»** на пустом экране или в настройках → «Данные». Открывать импорт Excel заранее не нужно.
3. Отключите сеть (или включите Offline в инструментах разработчика), перезагрузите страницу. Проверьте импорт локального `.xlsx`, оценки, настройки, статистику, экспорт и восстановление JSON-копии.
4. Закройте приложение и снова откройте без сети: словари и результаты должны сохраниться.

Если появилась надпись об обновлении, закройте все вкладки приложения и установленное PWA, затем откройте снова. При ошибке подготовки верните интернет и откройте приложение повторно. Очистка данных сайта браузером удаляет и офлайн-кеш, и локальные данные; резервные копии храните отдельно.

## Проверки

```sh
npm test
npm audit
```

Тесты проверяют правила статусов и приоритетов, ограничение недавних карточек, чтение и анализ `.xlsx`, дедупликацию общих карточек, резервное копирование и сохранение прогресса между словарями. Офлайн-тесты собирают приложение по вложенному пути и выполняют полученный service worker с имитацией сети и кеша: проверяют первый запуск без сети после установки, доступность Excel, сбой загрузки и обновление версии. Проверка настоящего браузера описана выше.
