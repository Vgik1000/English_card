# Лексика

Персональный офлайн-тренажёр английских слов. Словари, настройки и история оценок хранятся в IndexedDB текущего браузера; серверной части и передачи данных нет.

## Запуск

Требуется Node.js 20 или новее.

```sh
npm ci
npm run dev
```

Vite покажет локальный адрес. Для production-сборки и локального предпросмотра:

```sh
npm test
npm run build
npm run preview
```

## Excel

Импортируется первый лист файла `.xlsx`. Первая строка должна содержать семь заголовков: `English`, `Russian`, `Transcription`, `Past Simple`, `Past Participle`, `Example EN`, `Example RU`. Обязательны только первые два поля. Формулы не вычисляются, ячейки с формулами не импортируются как текст.

Сгенерировать заполненный пример-шаблон можно командой `npm run template`; файл появится как `Шаблон словаря.xlsx` в корне проекта. Импорт и чтение Excel выполняются локально в браузере.

Повторный импорт заменяет состав выбранного словаря после подтверждения. Пары EN/RU сравниваются без учёта регистра и лишних пробелов. Общая пара в разных списках использует одну карточку и общую историю повторов.

## Данные и резервная копия

Настройки, импорт/обновление списков, статистика и ручные JSON-копии находятся за кнопкой настроек. Резервная копия включает версии формата и базы, словари, карточки, связи, историю оценок, настройки и техническую историю недавнего выбора. Восстановление сначала проверяет структуру и ссылки и заменяет базу одной транзакцией.

Данные не синхронизируются между устройствами. Очистка данных браузера, удаление установленного PWA или смена телефона могут привести к потере словарей и статистики. Сохраняйте копии в отдельном надёжном месте.

## GitHub Pages

Включите GitHub Actions как источник GitHub Pages. Workflow `.github/workflows/deploy.yml` собирает приложение с базовым путём `/<имя-репозитория>/` и публикует `dist`. Для ручной сборки с этим путём:

```sh
VITE_BASE_PATH=/english-trainer/ npm run build
```

Service worker кэширует только ресурсы приложения на том же origin. Новая версия заменяет кэш кода, не затрагивая IndexedDB. Для локальной проверки офлайн-поведения используйте production-предпросмотр по HTTPS или `localhost`.

## Проверки

```sh
npm test
npm audit
```

Тесты проверяют правила статусов и приоритетов, ограничение недавних карточек, чтение и анализ `.xlsx`, дедупликацию общих карточек и сохранение прогресса между словарями.
